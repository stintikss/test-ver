# Тестовый сайт для Vercel

Простой статический сайт без фреймворков.

## Деплой на Vercel

1. Распакуйте ZIP.
2. Откройте Vercel и выберите **Add New → Project**.
3. Загрузите содержимое проекта или подключите Git-репозиторий.
4. Для этого проекта не нужны Build Command и Output Directory.
5. Нажмите **Deploy**.

После деплоя Vercel выдаст публичную ссылку на сайт.
